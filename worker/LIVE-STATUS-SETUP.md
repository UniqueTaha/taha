# راه‌اندازی وضعیت لایو با Cloudflare رایگان

سایت روی GitHub Pages می‌ماند و Worker از نشانی `workers.dev` کلودفلر در دسترس است؛ لازم نیست DNS دامنه را تغییر دهید یا Proxy کلودفلر را روشن کنید. Worker وضعیت عمومی آپارات را می‌خواند، نتیجه را ۳۰ ثانیه کش می‌کند و فقط `live`، `offline` یا `unknown` برمی‌گرداند. اگر Worker نتواند به آپارات وصل شود، صفحه منبع مستقیم مرورگر و فایل تازه‌ی `/live-status.json` را هم امتحان می‌کند.

## پیش‌نیازها

- Node.js نصب باشد و پوشه `worker` در PowerShell باز شود.

## استقرار

1. در PowerShell از ریشه پروژه اجرا کنید:

   ```powershell
   Set-Location ".\worker"
   npx.cmd wrangler login
   npx.cmd wrangler deploy
   ```

   استفاده از `npx.cmd` در ویندوز مانع خطای Execution Policy پاورشل می‌شود و نیازی به تغییر تنظیمات امنیتی ویندوز نیست.

2. پس از استقرار، این نشانی را باز کنید:
   `https://uniquetaha-live-status.tahakazrwny.workers.dev/live-status`

   پاسخ سالم یکی از این حالت‌هاست:
   `{"status":"live","checkedAt":"..."}`
   یا
   `{"status":"offline","checkedAt":"..."}`

   اگر پاسخ `unknown` باشد یا HTTP 502 بگیرید، Worker اجرا شده ولی به API آپارات نرسیده یا پاسخ API عوض شده است. در این حالت صفحه خودش منابع جایگزین را امتحان می‌کند. پاسخ 404 معمولاً یعنی Route هنوز به Worker وصل نشده یا DNS روی ابر نارنجی نیست.

3. این نشانی در `site/index.html` تنظیم شده است. تغییرات فایل سایت را در GitHub منتشر کنید؛ نیازی به تغییر DNS یا Route دامنه نیست.

## عیب‌یابی

- در Cloudflare بخش **Workers & Pages**، وضعیت آخرین Deploy و لاگ Worker را بررسی کنید.
- اگر نشانی `workers.dev` پاسخ 404 داد، مطمئن شوید از فایل `worker/wrangler.toml` deploy کرده‌اید و نام Worker در URL با نامی که Wrangler چاپ کرد یکی است.
- GitHub Actions یا Workerهای رایگان ممکن است از شبکه‌ای خارج از ایران به آپارات وصل شوند. کد در خطا هرگز وضعیت را به‌اشتباه `offline` نمی‌زند؛ اگر API در دسترس نباشد، وضعیت `unknown` خواهد بود.
- فایل `site/live-status.json` می‌تواند به‌عنوان fallback به‌روزرسانی شود؛ timestamp قدیمی‌تر از ۴۵ دقیقه پذیرفته نمی‌شود.

## هزینه و حریم خصوصی

این Worker نیازی به توکن GitHub، دیتابیس، KV یا پلن پولی ندارد. پاسخ عمومی فقط شامل وضعیت و زمان بررسی است و عنوان/اطلاعات دیگر کانال را برنمی‌گرداند. کش ۳۰ ثانیه‌ای از درخواست‌های تکراری به آپارات کم می‌کند.
