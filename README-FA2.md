# روش جایگزین به‌روزرسانی وضعیت لایو

راهنمای اصلی این پروژه در [README.md](./README.md) است. تمام فایل‌ها، از جمله اسکریپت‌های زیر، در همین پوشهٔ اصلی باقی می‌مانند.

## ارسال وضعیت با رایانهٔ داخل ایران

اگر سرویس Worker از شبکهٔ خودش به آپارات دسترسی ندارد، می‌توان از `push_live_status.py` روی رایانه‌ای استفاده کرد که هم به آپارات و هم به GitHub دسترسی دارد.

1. از Python 3 اجرا کنید؛ این اسکریپت به پکیج جانبی نیاز ندارد.
2. متغیرهای محیطی `GITHUB_TOKEN`، `GITHUB_REPO` و در صورت نیاز `GITHUB_BRANCH` را تنظیم کنید. توکن باید فقط به مخزن لازم و مجوز `Contents: Read and write` دسترسی داشته باشد.
3. برای اجرای دستی، از همین پوشه دستور `python push_live_status.py` را اجرا کنید. `run.bat` نمونه‌ای برای ویندوز است و باید مقادیر نمونهٔ داخل آن را شخصی‌سازی کنید.
4. توکن واقعی را در نسخهٔ عمومی فایل‌ها یا مخزن قرار ندهید. در صورت افشا، توکن را باطل کنید.

workflow فعال GitHub Actions در `.github/workflows/live-status.yml` قرار دارد؛ این تنها فایل پروژه در زیرپوشه است، چون GitHub workflow را فقط از این مسیر اجرا می‌کند. Action هر ۵ دقیقه endpoint عمومی Cloudflare Worker را می‌خواند و وقتی وضعیت معتبر باشد، `live-status.json` را فقط هنگام تغییر وضعیت یا گذشت ۲۰ دقیقه به‌روزرسانی می‌کند. اگر Worker خطا دهد یا وضعیت `unknown` باشد، فایل دست‌نخورده می‌ماند و پس از ۴۵ دقیقه سایت آن را رد می‌کند.
