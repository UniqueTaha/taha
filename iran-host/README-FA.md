# وضعیت لایو آپارات

برای راه‌اندازی رایگان، ابتدا Worker کلودفلر را از پوشه `worker` مستقر کنید؛ راهنمای کامل در `worker/LIVE-STATUS-SETUP.md` است. Worker از مسیرهای `/live-status` دامنه سایت در دسترس است و صفحه آن را به‌صورت خودکار امتحان می‌کند. اگر Worker نتواند به آپارات وصل شود، وضعیت «نامشخص» می‌ماند و سایت به‌اشتباه آفلاین نشان نمی‌دهد.

اگر Worker از شبکه خودش به آپارات دسترسی نداشت، می‌توانید یکی از گزینه‌های زیر را به‌عنوان منبع جایگزین به کار ببرید.

## گزینه ۱: هاست PHP ایرانی (ساده‌ترین)
1. روی یک هاست ایرانی (cPanel یا DirectAdmin) یک ساب‌دامین بساز، مثلاً `api.uniquetaha.ir`، و SSL رایگان رو روش فعال کن.
2. فایل `live-status.php` رو تو `public_html` اون ساب‌دامین آپلود کن.
3. این آدرس رو تو مرورگر باز کن: `https://api.uniquetaha.ir/live-status.php`
   باید چیزی شبیه `{"status":"offline","checkedAt":"..."}` ببینی. اگه `{"status":"unknown"}` اومد، یعنی هاست به آپارات نرسیده (پیام خطا و حالت‌های بعد رو پایین ببین).
4. در `site/index.html` خط `const LIVE_STATUS_API = '/live-status';` را با آدرس HTTPS هاست خودتان جایگزین کنید:
   `const LIVE_STATUS_API = 'https://api.uniquetaha.ir/live-status.php';`
5. سایت را دوباره منتشر کنید.

## گزینه ۲: سرور مجازی ایرانی (VPS)
`live-status-server.mjs` رو با Node.js 18 یا بالاتر اجرا کن (`node live-status-server.mjs`) و پشت nginx یا Caddy با HTTPS بذارش. آدرس نهایی `https://.../live-status` می‌شه.

## نکته‌ها
- فقط از `https://uniquetaha.ir` و `https://www.uniquetaha.ir` اجازه خوندن داره (CORS).
- جواب ۳۰ ثانیه کش می‌شه، پس فشاری به آپارات نمیاد.
- اگه آپارات خطا بده یا API عوض بشه، هیچ‌وقت «آفلاین» نمی‌نویسه؛ «نامشخص» برمی‌گردونه.
- اگه جواب نامشخص بود: ممکنه هاست curl یا خروجی https نداشته باشه، یا آپارات آی‌پی اون هاست رو هم محدود کرده باشه. با پشتیبانی هاست چک کن.
- Worker کلودفلر منبع اصلی سایت است. در صورت استفاده از هاست PHP، آدرس آن را در `LIVE_STATUS_API` قرار دهید تا به‌عنوان منبع اول استفاده شود.
- کسی که از خارج ایران وارد بشه ممکنه به هاست ایرانی نرسه. اون هم «نامشخص» حساب می‌شه و مشکلی پیش نمیاد.
