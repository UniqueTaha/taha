# سایت یونیک طاها (UniqueTaha)

همه فایل‌ها عمداً در یک پوشه هستن. تنها استثنا `.github/workflows/live-status.yml` هست، چون GitHub فقط از همین مسیر Action رو اجرا می‌کنه.

## فایل‌ها
| فایل | کار |

| `style.css`, `app.js`, `fx.js`, `pwa.js` | ظاهر؛ رفتار صفحه و وضعیت لایو؛ جلوه‌ها (ورود، رادار، ایردراپ)؛ نصب برنامه. هر کدوم با `?v=` تو `index.html` صدا زده می‌شن |

## برنامه موبایل (PWA)
سایت روی اندروید، آیفون و کامپیوتر مثل یک برنامه نصب می‌شه و آفلاین هم باز می‌شه. جزئیات و ساخت APK تو `APP-GUIDE-FA.md` هست.
- اندروید: نوار «نصب برنامه» خودکار میاد یا منوی ⋮ ← Install app. آیفون: Safari ← Share ← Add to Home Screen. کامپیوتر: آیکون نصب کنار نوار آدرس.
- وضعیت لایو و Worker هیچ‌وقت کش نمی‌شن. وقتی صفحه روی شبکه کند بیش از ۰٫۸ ثانیه طول بکشه، نسخهٔ کش‌شده زودتر نمایش داده می‌شه و نسخهٔ تازه در پس‌زمینه به‌روزرسانی می‌شه. برنامه نصب‌شده نوار نصب رو نشون نمی‌ده.
- بعد از انتشار حتماً با HTTPS باز کن و تو Chrome تب Application ← Manifest را ببین.
- اگه آیکون یا تصویر عوض کردی، `python bump-version.py` رو بزن.

## جلوه‌های گیمینگ (همه داخل `index.html`)
- **ورود Drop-in** با هواپیمای واقعی C-130: اول از روبه‌رو نزدیک می‌شه، بعد به نیم‌رخ می‌چرخه، جامپر از رمپ عقبش می‌پره و آخر سه‌چهارم از پشت دور می‌شه (موقعیت، اندازه، کج شدن و چرخش با حالت سه‌بعدی هر فریم حساب می‌شه). هواپیما و انیمیشن‌های چتر یک ساعت مشترک دارن تا جامپر همیشه از رمپ جدا بشه. هر نشست یک بار (رد کردن با کلیک/Esc/Enter/Space)، **رادار مینی‌مپ** (دکمه MAP یا کلید `M`) و **ایردراپ** (همون C-130 از بالای صفحه رد می‌شه و جعبه قرمز با برزنت آبی از رمپش می‌افته، کلید `D`). `?intro` و `?airdrop` آخر آدرس برای تست سریع، `?fx=full` برای حرکت کامل وقتی انیمیشن سیستم کم شده.
- همه فقط تزئینی هستن و هر کدوم جدا اجرا می‌شه تا خرابی یکی بقیه رو نبره.

## بعد از هر تغییر
فایل‌های `style.css`، `app.js`، `fx.js`، `pwa.js` یا یک تصویر رو عوض کردی؟ قبل از آپلود این رو بزن:

    python bump-version.py

این اسکریپت کنار هر فایل یک `?v=` تازه می‌نویسه و نسخه کش `sw.js` رو عوض می‌کنه. بدون این کار، بعضی بازدیدکننده‌ها ممکنه چند دقیقه صفحه جدید رو با CSS یا JS قدیمی ببینن. اگه فقط متن `index.html` رو عوض کردی نیازی نیست.

## سبک بودن
- **حجم**: صفحه و تصویرها فقط وقتی لازم باشن دانلود می‌شن. بازدیدکننده برگشتی هواپیما و آیکون نصب رو نمی‌گیره و لوگو و آیکون‌ها خیلی کوچک شدن.
- **حالت سبک (lite)**: روی گوشی‌های ضعیف (۴ هسته یا کمتر، RAM حدود ۲ گیگ یا کمتر، حالت صرفه‌جویی داده، شبکه 2G/3G) خودکار روشن می‌شه: ستاره‌ها یک‌سوم، بدون ذرات و شهاب، بدون بلور پس‌زمینه و بدون ابرهای ورود. روی 2G/3G و حالت صرفه‌جویی داده، ورود نمایشی و سه تصویر هواپیما هم بارگیری نمی‌شن تا محتوای سایت زودتر دیده بشه؛ برای آزمایش ورود `?intro` رو اضافه کن. دستی: `?lite` روشن و `?lite=0` خاموش.
- اندازه‌گیری‌ها تو `PERFORMANCE-FA.md` هست.

## انتشار
1. همه فایل‌ها (با `.github`) رو تو ریشه ریپوی GitHub Pages بذار. `CNAME` رو تو ریشه نگه دار.
2. Worker: تو همین پوشه `npx.cmd wrangler login` و بعد `npx.cmd wrangler deploy` رو اجرا کن. آدرس `…workers.dev/live-status` باید `live`، `offline` یا `unknown` بده.
3. GitHub: Settings ← Actions ← General ← Workflow permissions رو روی **Read and write** بذار. بعد تب Actions ← Update live status ← Run workflow.
4. `uniquetaha.ir/live-status.json` رو باز کن. باید `checkedAt` تازه ببینی.

## وضعیت لایو چطور کار می‌کنه
سایت این منابع رو هم‌زمان چک می‌کنه و اولین جواب معتبر رو نشون می‌ده:
1. Worker کلودفلر (تازه‌ترین).
2. خود آپارات از مرورگر بازدیدکننده (فقط اگه آپارات CORS اجازه بده).
3. `/live-status.json` هم‌دامنه (حداکثر ۴۵ دقیقه قدیمی).

اگه هیچ‌کدوم جواب ندن، چیپ وضعیت مخفی می‌شه و دکمه فقط «رفتن به کانال آپارات» رو نشون می‌ده. هیچ‌وقت «آفلاین» یا «لایو» قدیمی نشون داده نمی‌شه.

آپارات ممکنه به درخواست‌های خارج از ایران جواب نده. اگه Worker و Action بعد از راه‌اندازی `unknown` دادن، از `push_live_status.py` روی یک کامپیوتر داخل ایران یا از `live-status.php` روی هاست ایرانی استفاده کن.

## امنیت
- `run.example.bat` رو کپی کن به `run.bat`، توکن رو فقط اونجا بذار و `run.bat` رو هیچ‌وقت آپلود نکن (تو `.gitignore` هست).
- توکن GitHub باید فقط به همین ریپو و فقط **Contents: Read and write** دسترسی داشته باشه.
- هیچ‌جای سایت تاریخ تولد، سن یا شهر ننویس.

## سئو بعد از انتشار
1. سایت رو تو Google Search Console ثبت کن، `sitemap.xml` رو بفرست و برای صفحه اصلی Request Indexing بزن. تو Bing Webmaster Tools هم همین.
2. لینک `https://uniquetaha.ir` رو تو بیو و توضیحات آپارات، یوتیوب، اینستاگرام، تلگرام و روبیکا بذار.
3. اسم نمایشی همه حساب‌ها رو یکی کن، مثلاً «یونیک طاها | UniqueTaha».
4. لینک `INDEXNOW-README.txt` رو یک بار تو مرورگر باز کن.
