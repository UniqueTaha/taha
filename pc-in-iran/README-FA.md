# به‌روزرسانی وضعیت لایو آپارات

## راهکار اصلی: Cloudflare Worker و GitHub Pages

سایت از GitHub Pages سرو می‌شود و Worker کلودفلر از مسیر `/live-status` وضعیت را می‌دهد. برای استقرار رایگان Worker و اتصالش به دامنه، راهنمای [`worker/LIVE-STATUS-SETUP.md`](../worker/LIVE-STATUS-SETUP.md) را دنبال کنید. در حالت عادی نیازی به اسکریپت این پوشه، توکن GitHub یا GitHub Actions نیست.

اگر در endpoint کلودفلر `unknown` یا HTTP 502 دیدید، یعنی Worker نتوانسته به API آپارات دسترسی پیدا کند. در این شرایط می‌توانید از روش پشتیبان این صفحه استفاده کنید؛ کامپیوتر باید آپارات را از اینترنت ایران بخواند.

---

## روش پشتیبان: ارسال وضعیت از کامپیوتر داخل ایران به GitHub

این روش زمانی کاربرد دارد که Worker کلودفلر از شبکه خودش نتواند به آپارات دسترسی پیدا کند. سایت فایل `live-status.json` را به‌عنوان fallback می‌خواند و اگر زمان آن از ۴۵ دقیقه بیشتر باشد، وضعیت را نمی‌پذیرد.

### گزینه ۱: خود مرورگر بازدیدکننده
مرورگر کاربر ایرانی از ایران به آپارات وصل می‌شه، پس مشکل آی‌پی نداره. فقط باید آپارات اجازه خوندن بین‌دامنه‌ای (CORS) بده. این رو تست کن:

1. سایت `uniquetaha.ir` رو تو مرورگر با اینترنت ایران (بدون فیلترشکن) باز کن.
2. F12 رو بزن، تب Console، این رو بچسبون و Enter:
   `fetch('https://www.aparat.com/api/fa/v2/Live/LiveStream/show/username/uniquetaha').then(r=>r.json()).then(console.log).catch(console.error)`
3. اگه یک آبجکت با `live_status` چاپ شد، راه ۱ کار می‌کنه و تمومه. هیچ کار دیگه‌ای لازم نیست.
4. اگه خطای CORS اومد (`blocked by CORS policy`)، برو سراغ راه ۲.

### گزینه ۲: یک کامپیوتر داخل ایران وضعیت را به GitHub می‌فرستد
اسکریپت `push_live_status.py` هر دقیقه وضعیت آپارات رو می‌خونه و فقط وقتی عوض شد (یا هر ۲۰ دقیقه) فایل `live-status.json` رو تو ریپوی GitHub آپدیت می‌کنه. سایت اون فایل رو می‌خونه.

1. Python 3 نصب باشه (فقط خود پایتون، پکیج اضافه نمی‌خواد).
2. تو GitHub یک **Fine-grained token** بساز: Settings → Developer settings → Personal access tokens → Fine-grained. فقط همین ریپو رو انتخاب کن و فقط **Contents: Read and write** بده.
3. فایل `run.bat` رو با اطلاعات خودت پر کن و تو Task Scheduler هر ۱ دقیقه اجراش کن:
   `schtasks /create /sc minute /mo 1 /tn "AparatLiveStatus" /tr "C:\path\run.bat"`
4. بعد از چند دقیقه `https://uniquetaha.ir/live-status.json` رو باز کن. باید `status` و `checkedAt` تازه ببینی.

### نکته‌های مهم
- فایل `live-status.json` اولیه عمداً قدیمیه (۲۰۲۶-۰۱-۰۱). تا اسکریپت اولین بار اجرا نشه، سایت «نامشخص» نشون می‌ده.
- اگه کامپیوتر خاموش باشه، بعد از ۴۵ دقیقه وضعیت «نامشخص» می‌شه (نه «لایو» یا «آفلاین» قدیمی).
- کامپیوتر باید از **اینترنت ایران** به آپارات وصل بشه. اگه فیلترشکن روشنه و همه ترافیک رو می‌بره، آپارات آی‌پی خارجی می‌بینه و جواب نمی‌ده. اگه GitHub بدون فیلترشکن باز نمی‌شه، باید فقط ترافیک GitHub از فیلترشکن بره (split tunneling).
- توکن رو جز تو `run.bat` تو هیچ جای دیگه (مخصوصاً GitHub) نذار. اگه لو رفت، حذفش کن و یکی جدید بساز.
- هر تغییر وضعیت یک commit می‌سازه. تاریخچه ریپو شلوغ می‌شه، ولی چیزی خراب نمی‌شه.
