# راهنمای انتشار سایت

همهٔ فایل‌های این پروژه در همین پوشهٔ اصلی قرار دارند؛ برای انتشار سایت آن‌ها را به زیرپوشه منتقل نکنید. فایل `index.html` صفحهٔ اصلی است و باید همراه فایل‌های تصویر، آیکون، manifest، `robots.txt` و `sitemap.xml` در ریشهٔ GitHub Pages منتشر شود.

`CNAME` را هم در ریشه نگه دارید و دامنه را در تنظیمات Pages فعال کنید. اگر دامنه 404 می‌دهد، وضعیت آخرین انتشار Pages، ریشهٔ انتشار، دامنهٔ سفارشی و DNS را بررسی کنید؛ خطای 404 هاست با تغییر کد HTML رفع نمی‌شود.

Worker وضعیت لایو نیز در همین پوشه است. از PowerShell در این مسیر اجرا کنید:

```powershell
npx.cmd wrangler login
npx.cmd wrangler deploy --config .\wrangler.toml
```

راهنمای کامل و توضیح منابع جایگزین وضعیت لایو در [README.md](./README.md) آمده است. سایت در صورت خطا یا کهنگی داده، وضعیت «نامشخص» را نمایش می‌دهد.

فقط workflow زمان‌بندی‌شدهٔ GitHub، به‌دلیل الزام خود GitHub، در `.github/workflows/live-status.yml` قرار دارد و فایل `live-status.json` را از Worker به‌روزرسانی می‌کند. باقی فایل‌ها در ریشه می‌مانند.
